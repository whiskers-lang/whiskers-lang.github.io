01 / WHY WHISKERS

Templates should say what they mean.

Truthy is not the same as present. Missing is not the same as null. And deeply nested context should not turn a simple name into a guessing game.

02 / THE LANGUAGE

Small syntax.
Useful distinctions.

Whiskers adds focused tools to Mustache without changing its declarative character.

FOUR QUESTIONS, FOUR ANSWERS

Stop overloading truthiness.

Test whether a key exists, is absent, is non-null, or is explicitly null. Standard # and ^ sections still handle truthiness.

{{*account}} key exists {{/account}}
{{%account}} key is absent {{/account}}
{{~account}} value is non-null {{/account}}
{{?account}} value is null {{/account}}

CONTEXT WITHOUT GUESSWORK

Name the scope you mean.

Bind any pushed context with :alias. Aliases remain available through nesting, while @root always points to top-level data.

{{#employer :company}}
  {{#employee}}
    {{company.name}}: {{name}}
  {{/employee}}
{{/employer}}

LOOPS THAT KNOW WHERE THEY ARE

Use position without reshaping data.

Lists expose @index, @number, @first, @last, and @length inside iteration.

{{#items}}
  {{@number}}/{{@length}} — {{name}}
  {{^@last}} · {{/@last}}
{{/items}}

FAIL EARLY, NOT QUIETLY

Turn missing data into an error.

Wrap critical output in @strict. Missing lookups throw instead of silently rendering an empty string. Presence checks remain safe.

{{#@strict}}
  Hello, {{customer.name}}!
{{/@strict}}

04 / GET STARTED

Render your first template.

The .NET package targets netstandard2.0 and runs across modern .NET, .NET Framework 4.6.1+, Mono, Xamarin, and Unity.

1. Install
$ dotnet add package Whiskers
2. Render
using Whiskers;

var output = Renderer.Render(
  "Hello, {{name}}!",
  new { name = "world" }
);
